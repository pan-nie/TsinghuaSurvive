<b>LaTeX 不是“更高级的 Word”。</b> 它的真正优势只有两条：<b>公式和交叉引用不会乱</b>，以及<b>格式和内容分离</b>——你只管写内容，编号、目录、参考文献格式交给模板。

所以判断标准很简单：<b>你的文档里有没有大量公式、编号和引用。</b> 有，就值得学；没有，Word 更快。

## 什么时候真的需要它

| 你的情况 | 建议 |
| --- | --- |
| 实验报告里有成串的公式，还要在正文里引用“式 (3)” | 用 LaTeX，你会省下大量手动编号的时间 |
| 课程论文、综述、毕设，有参考文献格式要求 | 用 LaTeX（配合[文献管理工具](/skills/reference-manager/)） |
| 老师或期刊直接给了 `.tex` 模板 | 没得选，照着模板填 |
| 两三页、以文字为主、公式零星一两个 | 用 Word，更快 |
| 需要精确控制每一处版式（海报、简历） | 两个都不太合适，用专门的设计工具 |
| 几个人要同时改同一份文档 | 在线协作（例如校内 Overleaf），但要先确认内容能不能上传 |

> 它在课程、科研、实习里分别用在哪
>
> -   <b>课程</b>：实验报告、数学类作业、课程论文——凡是“公式多、要编号”的地方。
> -   <b>科研</b>：基本是默认选项。投稿时期刊会给官方模板，参考文献用 `.bib` 文件管理，改格式只要换一行。
> -   <b>实习</b>：直接用到的机会不多，但“内容与格式分离、用工具生成编号”的思路在写技术文档时一样成立。

> 先看模板，再决定学不学
>
> 很多课程会直接给模板。<b>有模板的话，你要学的东西会少一大半</b>——只需要知道往哪填内容、怎么编译，不需要从零搭一篇文档。

## 马上能做的

- [ ] 问清楚下学期哪门课会用到 LaTeX，把那份<b>模板</b>先拿到手。

- [ ] 用模板把一份旧报告重排一遍，目标只有一个：<b>能编译出 PDF</b>。

- [ ] 把公式、表格、图片三个最常用的写法各抄一个例子进你的文档。

- [ ] 故意删掉一个 <code>\end{...}</code>，看一遍报错长什么样，学会从<b>第一条</b>报错定位行号。

- [ ] 定一个备份习惯：交作业前把整个项目导出成压缩包，存到本地和<a href="https://cloud.tsinghua.edu.cn/">校内云盘</a>。

## 最小可用路径

### 第 1 步：选在哪里编译

只有两个选择，先选一个，不要纠结：

-   <b>本地装发行版</b>：装一次，之后离线可用，适合长期用（发行版见[TUG 的 TeX Live 页面](https://tug.org/texlive/)）。
-   <b>用在线平台</b>：不用装几个 G 的东西，换电脑也能接着写，多人协作方便（校内入口见下一节）。

> 第一次用别折腾环境
>
> 第一次接触 LaTeX 的人，最常见的失败不是语法不会，而是<b>卡在安装和编译配置上耗掉一整天</b>。先用在线平台把内容写出来，环境问题以后再说。

### 第 2 步：认识六个概念

| 概念 | 长什么样 | 作用 |
| --- | --- | --- |
| 文档类 | `\documentclass{...}` | 决定整篇的版式，<b>模板已经给好了，不要改</b> |
| 导言区 | `\usepackage{...}` | 引入功能宏包，模板一般也写好了 |
| 环境 | `\begin{...} ... \end{...}` | 表格、图、公式、列表都是环境，<b>必须成对</b> |
| 章节 | `\section{}\subsection{}` | 只管层级，编号和目录自动生成 |
| 引用 | `\label{}` + `\ref{}` / `\cite{}` | 交叉引用和文献引用，<b>永远不要手打编号</b> |
| 编译 | 引擎 + 跑几遍 | 见下一步 |

### 第 3 步：接受“要编译两遍”

第一次编译后有几种情况是<b>正常的</b>，不是出错：

-   目录、公式编号、图表编号显示成 `??` —— 再编译一次。
-   参考文献没出来 —— 通常还要跑一次参考文献处理（BibTeX 一类的工具），顺序以模板说明为准。
-   每次大改结构后，编号才会稳定下来。

<b>所以：改完结构一定完整编译两遍再交。</b>

### 第 4 步：从第一条报错看起

LaTeX 的报错体验不友好，但有规律：

1.  报错信息里会带<b>行号</b>，先跳到那一行。
2.  <b>只看第一条报错。</b> 后面的往往是第一条的连锁反应。
3.  最常见的原因是环境没闭合（少一个 `\end`）、少了一个 `}`、用了一个没引入的宏包。
4.  学会二分法：把后半段内容注释掉，看还报不报错，快速缩小范围。

### 第 5 步：把文档拆成多个文件

一篇长文档不要全写在一个文件里。按章节拆成几个文件，用 `\input{}` 在主文件里拼起来。好处很直接：<b>改第三章的时候不需要在前面几百行里滚动。</b>

## 中文排版的注意点

中文在 LaTeX 里最容易出问题的不是内容，而是<b>引擎和字体</b>：

-   <b>引擎</b>：处理中文通常要用支持中文的引擎（常见的是 xelatex、lualatex 这一类），具体以你的模板说明为准。用错引擎的典型症状是中文直接不显示或报错。
-   <b>字体</b>：模板一般会指定字体。如果本机缺字体，编译会失败并在报错里写出缺的是哪个——按名字装上就好。
-   <b>不要手动排版</b>：中文的断行、标点挤压、中英文之间的空隙由宏包处理。<b>手打空格去对齐，换一台机器就会全乱。</b>
-   <b>中英混排</b>：数字和英文单词两侧的空隙交给宏包，不要自己加空格。
-   <b>标点</b>：正文里的中文标点用全角；引号、破折号的写法以模板为准，别的一半中文一半英文。
-   <b>图片</b>：论文和报告里的图尽量用矢量格式（PDF/SVG）或高分辨率位图，截图打印出来会糊。

> 不要手打任何编号
>
> 第几个公式、第几节、第几条参考文献——<b>全部用引用命令让 LaTeX 自己生成</b>。手打的编号只要中间插一段内容就会全部错位，而且这种错误交作业前很难被发现。

## 校内资源与外部文档

<b>校内 Overleaf</b> 是学校提供的在线 LaTeX 平台，入口是 [overleaf.tsinghua.edu.cn](https://overleaf.tsinghua.edu.cn/)。它的价值在于：不用在本机装发行版、换电脑也能写、多人协作改同一份文档。

> 具体流程以官方说明为准
>
> 校内 Overleaf 的<b>登录方式、是否需要校园网或 VPN、项目数量与编译时长限制</b>，由学校信息化部门规定并可能调整。本文不写这些细节——写错了会让你在截止前一小时抓瞎。请以站点首页的官方说明为准，入口也可以在[信息门户](https://info.tsinghua.edu.cn/)里找。

> 不要往在线平台传不该传的东西
>
> <b>未公开发表的研究数据、涉密或受限材料、他人的个人信息、课程明确要求不得外传的资料</b>，一律不要上传到任何在线平台（包括校内平台和公共平台）。上传前先问自己一句：这份东西允许离开我的电脑吗？不确定就先问老师。

<b>本地安装</b>用 [TeX Live](https://tug.org/texlive/)：一次装好、离线可用、宏包齐全。安装包较大，下载慢的话先在[清华镜像站](https://mirrors.tuna.tsinghua.edu.cn/)里找有没有对应镜像。

<b>宏包和用法</b>查 [CTAN](https://www.ctan.org/)（宏包的官方索引）和 [Overleaf 的文档库](https://www.overleaf.com/learn)（按“我想做某件事”组织，对初学者最好用）。

## 交作业的坑

> 警告
>
> -   <b>只看最后一晚的编译结果。</b> 在干净环境里从头编译一次，才能发现“缺字体”“本地文件没带上”这类问题。
> -   <b>改动模板的页边距和字号。</b> 看起来更舒服，但可能直接违反格式要求。
> -   <b>参考文献生成后不抽查。</b> 作者、年份、页码、卷期是工具出错最多的地方，交之前随手核几条。
> -   <b>公式编号和正文对不上。</b> 通常是改完没重新编译。
> -   <b>交错了文件。</b> 是交 PDF、还是同时交源码和 PDF，<b>以课程要求为准</b>，不确定就问助教。
> -   <b>用截图当图。</b> 屏幕上看着清楚，打印出来是一团糊。
> -   <b>中文文档用了不支持中文的引擎或宏包组合。</b> 症状是中文消失、乱码或直接编译失败。
> -   <b>一份文档只存在在线平台上。</b> 断网、平台维护、账号异常都会让你当天交不上。<b>留一份本地导出。</b>
