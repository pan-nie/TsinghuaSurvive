## 这篇文章不做什么

-   <b>不写任何具体项目名称与其适用对象</b>。学校层面和院系层面的项目设置会调整，写死一个名字只会让人找错地方。
-   <b>不写时间点和截止日期</b>。任何没有注明适用年份的时间安排都不写；有亲历者核实过的版本，请以“某年某院系”的形式写进来。

-   <b>不写资格判定的硬指标</b>。年级限制、成绩要求、是否需要先修课，一律以项目当年通知为准。

## 已经能确认的部分：SRT 与挑战杯（2026 年口径）

这篇整体还是骨架，但有两类事情<b>可以写清楚</b>，因为它们不依赖你报哪个院系的项目：

### SRT：最容易上手的那条路

<b>SRT（学生研究训练，Students Research Training）是本科生在教师指导下、以学生为主体开展的课外教学研究活动</b>。它的定位不是“发论文”，而是：

-   接触更接近实际的科研环境，训练<b>查阅文献、制定方案、分析论证、设计或试验、分析与总结</b>这些能力；
-   <b>完成 SRT 计划可以获得相应的学分和成绩</b>；
-   最早的收益是<b>尽早进入实验室和课题组</b>，了解学科发展动向与前沿课题。不少人是在 SRT 里找到自己的兴趣，后来把它接成了研究生阶段的方向。

<b>报名窗口</b>：清华大学信息门户 → <b>应用导航 → 学习 → SRT</b>。这条路径 2026 年有效，具体开放批次与资格仍以门户里当期的说明为准。

### 挑战杯与各类科技赛事

-   <b>「挑战杯」学生课外学术科技作品竞赛始于 1983 年</b>，是清华历史最长、规模最大、学科最全、水平最高的综合性学生课外科技竞赛，宗旨是「<b>崇尚科学，追求真知，勇于创新，迎接挑战</b>」。
-   全校课外科技赛事以挑战杯为龙头，<b>每年由校科协与各院系科协组织 60 余项竞赛</b>。面向高年级的如机械创新设计大赛、「今经乐道」经济热点分析大赛、中国大学生工程实践与创新能力大赛；面向中低年级的专业类竞技赛如「自由能」杯化工车动力与控制大赛、结构设计大赛、硬件设计大赛；面向新生的兴趣赛如「芯动计划」科技冬令营、「碳中和+」创意创新大赛。
-   除此之外，学校层面还有以「<b>星火计划</b>」为代表的科研类因材施教计划（见[学校给你的支持](/campus/support-centers/)）。<b>哪个适合你，取决于你院系科协当年发什么</b>——同类赛事每年的名称与分组都可能变。

-   <b>SRT 立项申请每年分两批</b>，分别在<b>秋季学期和春季学期的学期初</b>进行，具体留意教务通知。

### 夏季学期：把实践环节单独排出来的那五周

清华从 <b>1985—1986 学年度</b>开始实行<b>三学期制</b>，即在秋季学期、春季学期之后增加一个<b>夏季学期</b>（也叫小学期）：

-   <b>夏季学期一般为 5 周</b>，由学校和院系安排教学活动；<b>学生暑假 5–7 周</b>（寒假一般为 5 周）。<b>夏季学期和暑假的先后顺序由院系确定</b>——所以“你们院是先上课还是先放假”要问本院系。
-   夏季学期一般安排<b>与专业学习有关的实践训练环节</b>，基础文科和理科专业也可以安排<b>暑期课程</b>。
-   这些环节包括<b>基础技能训练、专题研究训练、专业实习实践</b>，文件举的例子是认识实习、生产实习、金工实习、电子工艺实习、课程设计、专题实验等。
-   <b>夏季学期开设的课程，原则上每周计 1 学分。</b>

文件同时鼓励本科生<b>在不影响教学计划内学习的前提下</b>，利用暑假和寒假参加国内外社会实践活动、短期研修或交流项目。

### 创意创新创业教育：和 SRT 并列的几条通道

文件把“三创”教育单独列为一节。它的特点是：<b>项目多、各自归口不同</b>，所以“找谁报名”比“报什么”更容易搞错。

-   <b>大学生创新创业训练计划（大创计划）</b>：面向<b>全体非毕业班本科生</b>开放，鼓励个人或团队在导师指导下自主完成创新训练、创业训练和创业实践。<b>项目由学生自主立项、自行寻找指导教师</b>，鼓励跨院系、跨学科组队；项目可以来源于 SRT 项目延伸、校内科技赛事、实验室研究课题等。执行期一年，一般分<b>秋季学期和春季学期两批</b>立项，<b>创新训练类项目由各依托院系组织申报</b>，<b>创业类项目由校团委创业中心、清华「iCenter」和清华「x-lab」分别组织</b>。
-   <b>学生科技兴趣团队</b>：跨学科跨年级组建的科技创新团队，由<b>校团委</b>匹配活动室和指导教师团队、负责日常运营，企业提供资金、工程师指导、研发平台与实习机会。<b>每学期初面向全校同学零基础招新</b>，报名通知见「清华青年科创」微信号。
-   <b>大学生学术研究推进计划</b>：面向全校本科生，学生根据自身兴趣<b>自主立项研究</b>，学校匹配项目经费、指导教师与学术交流平台。分<b>院系项目</b>与<b>个人项目</b>两类，支持周期一般以<b>自然年</b>为周期；<b>个人项目由申请人向院系提出申请，院系评审后按推荐顺序提交校团委</b>。
-   <b>清华「iCenter」</b>：依托基础工业训练中心，是国内高校率先建成的校园创客空间，提供工业级加工设备与技术支持，开设人工智能创新创业能力提升证书项目及「创业导引」等课程，并支持中美青年创客大赛等赛事。
-   <b>清华「创+」</b>：由学校发起、<b>校团委具体运营</b>的创新创业教育服务平台，为学生创业者对接高校、政府与企业资源。
-   <b>清华「x-lab」</b>：<b>2013 年 4 月成立</b>，依托经济管理学院、由 14 个院系合作共建，接收学生、校友和老师的创意创新创业项目；<b>2013 年 12 月发起并主办首届清华大学「校长杯」创新挑战赛</b>。

<b>来源</b>：《清华大学本科生学习指南》（2023）第八节 8.4（2023 年口径）。

### 社会实践：学校鼓励“至少参加一次”

-   学生社会实践是学生走进社会，认知世情、国情、社情、民情的重要途径。文件写明的规模是：<b>每年有近 1000 支支队、10000 人次学生</b>在寒暑假和学期中开展国内外学习调研、专题调查、服务建设、专业认知等多种类型的实践，<b>超过 90% 的学生在学期间至少参与一次社会实践</b>。
-   组织与支持体系由<b>校团委</b>负责：学校在支持、培训、总结等方面提供系统支撑，学生可以通过校团委获取实践指导，公众号为「清华大学社会实践（THUpractice）」。
-   围绕国家战略与时代热点，文件提到的实践项目包括「新时代实践梦想计划」「江村学者」「支部同行」「乡村振兴工作站」等；为提升全球胜任力，学校还设立了本科生海外实践支持计划、全球胜任力海外实践课程等。

<b>来源</b>：《清华大学本科生学习指南》（2023）第八节 8.5（2023 年口径）。

### 综合论文训练：什么时候开始、走哪几个环节

综合论文训练就是常说的<b>毕业设计（毕设）</b>：

-   <b>时间</b>：一般安排在<b>第四学年第八学期</b>进行，<b>12–15 周</b>内完成。
-   <b>性质</b>：它是检验专业学习成效、训练解决实际问题能力的<b>一门必修综合课程，10–15 学分</b>。
-   <b>环节</b>：学校采用<b>过程管理与目标管理相结合</b>的模式，重点抓<b>开题、中期汇报、期终答辩</b>三个环节，并评选表彰优秀论文。
-   <b>产出</b>：学生在教师指导下综合运用所学知识，完成一项课题研究或相应的综合训练任务，<b>独立完成并答辩通过一篇「学士学位论文」</b>，在文献阅读与调研、方案设计与实施、资料分析与处理、案例分析等方面得到系统训练。
-   <b>海外综合论文训练</b>：自 <b>2017—2018 学年起</b>，教务处启动该项目，选派优秀本科生赴世界顶尖高校、顶尖专业或师从顶尖学者进行研究训练，具体留意教务通知。

<b>来源</b>：《清华大学本科生学习指南》（2023）第八节 8.6（2023 年口径）。规章依据为《清华大学本科生综合论文训练教学管理办法》。

## 环节概览：只写“有哪些环节”

本科生科研项目通常围绕<b>一条主线</b>展开：申报 → 立项 → 执行 → 中期 → 结题。但<b>具体环节的多少、名称与先后关系，各项目不同</b>，有的项目没有中期检查，有的把申报和立项合成一步。

| 环节 | 这一步在做什么 | 你需要在这里确认的事 |
| --- | --- | --- |
| <b>① 了解有哪些项目</b> | 搞清学校层面、院系层面分别有什么可报 | 项目名称、面向对象、由谁组织 |
| <b>② 找方向与导师</b> | 确定要做什么、找愿意指导的老师 | 是否必须自己找导师、导师需要什么身份 |
| <b>③ 申报与提交</b> | 按项目要求填写申报材料并提交 | 提交渠道、材料格式、是否需要签字盖章 |
| <b>④ 立项评审</b> | 由评审方决定是否立项与资助方式 | 评审形式、看什么、结果怎么通知 |
| <b>⑤ 执行与指导</b> | 真正做研究的阶段，通常需要定期汇报 | 汇报节奏、与导师的沟通方式 |
| <b>⑥ 中期检查</b> | 有的项目要求提交进展材料 | 是否有这一环、要交什么 |
| <b>⑦ 结题与验收</b> | 提交结题材料、可能答辩 | 验收标准、材料清单、期限 |
| <b>⑧ 后续认定</b> | 学分、经费结算、成果归属等收尾 | 由哪个部门认定、什么时候办 |

<b>顺序可能不完全是这样</b>：有的项目允许先立项再补导师确认，有的项目把评审放在执行之后。<b>这张表只用来定位“哪一步该问谁”，不是时间线。</b>

### 材料清单（只有类别，没有格式要求）

申报与结题材料通常属于几类：<b>申报类</b>（申请表、项目简介、研究计划或方案）、<b>人员类</b>（参与者信息、导师意见或签字）、<b>进展类</b>（中期报告、汇报记录）、<b>结题类</b>（结题报告、成果佐证、答辩材料）、以及<b>经费类</b>（预算表、报销票据）。具体格式、份数与盖章要求<b>一律以当年通知为准</b>。

> 先建一个文件夹，再谈内容
>
> 把这几类的空缺位置先建出来，能减少“以为还早、结果发现少一份签字材料”的情况。<b>材料的最大风险不是写不好，而是发现得太晚</b>——尤其是需要老师或部门签字的那几份。

## 需要核实的事实清单

下面每一条都要由亲历者填写，<b>每条请写明“适用年份 + 院系 + 项目名称”</b>。查不到就保持 `- [ ]`，不要猜。

- [ ] <b>要填什么</b>：学校层面与院系层面分别有哪些本科生科研项目（准确名称、面向哪个年级、由谁组织）。<b>去哪查</b>：学校与院系当年发布的本科生科研相关通知（链接待补）。

- [ ] <b>要填什么</b>：申报资格（年级、成绩、专业限制、是否要求先修课程）。<b>去哪查</b>：项目当年的申报通知（链接待补）。

- [ ] <b>要填什么</b>：申报的时间窗口与提交渠道（系统填报还是纸质表格、交给谁）。<b>去哪查</b>：项目当年通知与院系教务（链接待补）。

- [ ] <b>要填什么</b>：是否必须自己联系指导教师；导师的身份要求（职称、是否本校、能否跨院系）。<b>去哪查</b>：项目管理办法与院系教务（链接待补）。

- [ ] <b>要填什么</b>：导师需要出具什么材料（签字、意见、承诺书），以及老师通常需要多长时间处理。<b>去哪查</b>：申报材料要求与亲历者（链接待补）。

- [ ] <b>要填什么</b>：立项评审的形式（书面评审、答辩还是两者都有）与考查重点。<b>去哪查</b>：项目当年通知与亲历者（链接待补）。

- [ ] <b>要填什么</b>：立项结果以什么形式、由谁通知，多久能知道。<b>去哪查</b>：项目通知渠道与亲历者（链接待补）。

- [ ] <b>要填什么</b>：项目的执行周期、起止与结题期限，以及能否延期、延期怎么申请。<b>去哪查</b>：项目管理办法与院系教务（链接待补）。

- [ ] <b>要填什么</b>：是否有中期检查，需要提交什么，不交有什么后果。<b>去哪查</b>：项目当年的过程管理要求（链接待补）。

- [ ] <b>要填什么</b>：结题验收的要求（报告、成果、答辩）与通过标准。<b>去哪查</b>：项目结题通知（链接待补）。

- [ ] <b>要填什么</b>：中途退出、更换题目或更换导师的规则与后果。<b>去哪查</b>：项目管理办法与院系教务（链接待补）。

- [ ] <b>要填什么</b>：资助形式（是否给经费、是报销制还是额度制）、报销范围与报销流程。<b>去哪查</b>：项目经费管理办法（链接待补）。

- [ ] <b>要填什么</b>：能否认定学分、算哪一类学分、需要提交什么材料、什么时候认定。<b>去哪查</b>：培养方案与院系教务（链接待补）。

- [ ] <b>要填什么</b>：团队项目的规则（人数上限、分工怎么写、个人贡献如何认定）。<b>去哪查</b>：项目当年通知（链接待补）。

- [ ] <b>要填什么</b>：是否允许跨院系、跨专业参与或跨学科组队。<b>去哪查</b>：项目通知与院系教务（链接待补）。

- [ ] <b>要填什么</b>：项目成果的署名与知识产权归属规则（谁署名、按什么顺序、能否对外发表）。<b>去哪查</b>：项目管理办法与导师（链接待补）。

- [ ] <b>要填什么</b>：项目能否与毕业设计、课程项目、竞赛项目叠加或复用同一份工作。<b>去哪查</b>：院系教务与项目管理办法（链接待补）。

- [ ] <b>要填什么</b>：项目经历在保研、评奖等评价环节中如何被认定（是否计入、需要什么证明）。<b>去哪查</b>：院系当年的评价办法与教务（链接待补）。

- [ ] <b>要填什么</b>：遇到争议或问题时的咨询与申诉渠道（哪个部门负责、时限多久）。<b>去哪查</b>：项目管理办法与院系正式渠道（链接待补）。

> 填写时的三条纪律
>
> 1.  <b>注明适用年份、院系与项目名称</b>，没注明的条目读者无法判断是否还成立。
> 2.  <b>区分“文件写的”和“我经历的”</b>：前者写文件和年份，后者写“某年某院系个人经历”。
> 3.  <b>不确定就留着不填</b>。留空比写错安全得多——这也是这篇存在的意义。

## 怎么自己找信息

三类渠道的分工不一样，<b>只用一个一定会漏</b>：

| 渠道 | 能得到什么 | 注意事项 |
| --- | --- | --- |
| <b>官方文件与通知</b> | 项目名称、资格、时间、经费与学分的唯一权威口径 | 以当年正式发布为准；不要拿往年的当今年用 |
| <b>院系教务</b> | 本院系有哪些项目、材料细节、学分怎么认 | 泛泛的问题问不出结果，带着清单里的具体条目去问 |
| <b>人</b>（导师、学长学姐） | 真实的投入强度、评审氛围、踩过的坑 | 一个人的经历不等于普遍情况，至少问两三个人、且问清是哪一年 |

<b>公开资料</b>：校内信息门户与教学相关站点（如 [信息门户](https://info.tsinghua.edu.cn/)、[网络学堂](https://learn.tsinghua.edu.cn/)）是查正式通知的入口；学生自发维护的资料库可以帮你知道“有哪些选项”，但不能替代官方口径：

-   [清华大学计算机系学生科协技能引导文档](https://docs.net9.org/)
-   [软件学院 ReadMe 互助文档](https://ssast-readme.github.io/)
-   [未央书院学习资料](https://weiyangxuexi.github.io/)
-   [CS 自学指南](https://csdiy.wiki/)：不依赖校内项目的自学路线，适合先判断自己对什么方向有兴趣。

<b>站内相关</b>：怎么找导师、第一封邮件怎么写，见[怎么进实验室做科研](/research/finding-a-lab/)；项目管理与协作工具见[Git 与 GitLab](/skills/git-and-gitlab/)；文献怎么管理与引用见[文献管理工具](/skills/reference-manager/)；和老师沟通的方式见[怎么和老师、导师、辅导员沟通](/mindset/talking-to-advisors/)；绩点与各种资格的关系见[绩点到底是怎么算的](/academics/gpa/)。

> 问问题的顺序
>
> 先看官方文件把范围缩小，再带着<b>具体到条目</b>的问题去问人：“申报表要不要导师签字”“中期要交几份材料”——比“本科生科研难不难”有用一百倍。

## 常见误解

以下几条<b>不依赖任何当年的政策细节</b>，所以可以放心写：

1.  <b>以为“要先做出成果才能申报”。</b> 这类项目的设计初衷恰恰是给你从零开始的机会。<b>门槛通常在申报环节，而不是在成果环节。</b>
2.  <b>以为必须自己找好导师才能报。</b> 有的项目由学生自己联系导师，有的由院系匹配或指定，<b>顺序可能正好相反</b>。先去确认自己属于哪一种，别在第一步就卡住。
3.  <b>以为报了就有经费和学分。</b> 经费形式（报销制还是额度制）与学分认定口径差异很大，甚至可能没有。<b>把它当成额外收益，而不是申报理由。</b>
4.  <b>以为项目等于一篇论文。</b> 多数项目的产出是过程性材料、一段可写入材料的研究经历、以及“我喜不喜欢做研究”的答案。<b>把发论文当作唯一目标，失望概率很高。</b>
5.  <b>以为别人的经验能直接照搬。</b> 同一所学校不同院系、甚至同一院系不同年份，项目设置与材料要求都可能不同。<b>看别人的攻略只能当线索，条件必须自己核实。</b>
