> 本文尚未核实，不得作为报考与备考的依据
>
> 这篇目前<b>只有结构，没有事实</b>。科目类别、环节名称是“通常有哪些东西”的框架；<b>具体科目、分值、分数线、报名与考试时间全部留空</b>，等着亲历者逐条填写并注明适用年份。
>
> <b>不要用本文判断“我该考什么”“什么时候报名”“多少分能上”</b>。考研的规则同时受到<b>招生单位</b>和<b>报考点</b>两方面文件约束，任何一条写错都可能直接损失一年。

考研是本站路线图里明确标为<b>不能猜</b>的三篇之一。和保研、出国相比，它有一个额外特点：<b>你既是被考查者，也是一个要走完行政流程的报考者</b>——报名、确认、准考证、考场、复试，每一步都有硬性的行政要求。

所以这篇的重点是<b>把“必须核实的事”整理成不会漏项的清单</b>，而不是给建议。

## 这篇文章现在是什么状态

-   <b>状态</b>：未核实骨架（`status: draft`，没有核对日期）。
-   <b>谁来填</b>：近一两年真正<b>完整走完报名到录取</b>的人，最好覆盖<b>本校考生</b>和<b>外校报考者</b>两种情况（两者流程不同）。
-   <b>填什么</b>：下面「需要核实的事实清单」的每一条，注明<b>适用年份 + 报考单位/专业</b>。
-   <b>读者怎么用</b>：当成一张“我要去官方文件里确认哪些字段”的自查表，<b>不要</b>当成时间规划。
-   <b>最容易误导人的一点</b>：他人经验里的时间安排、科目结构、复习顺序，往往只对<b>那一年、那个单位、那个专业</b>成立。

## 这篇文章不做什么

-   <b>不写分数线与录取线</b>。国家线、院线、单科线、报录比，一个数字都不写——它们逐年变化，写死会直接误导人。
-   <b>不写报名与考试的具体时间</b>。没有注明适用年份的时间点不写；有亲历者核实过的，请写成“某年”的形式。
-   <b>不写具体科目、分值与参考书目</b>。科目结构随报考单位、专业方向、学位类型变化，以当年的招生目录与考试大纲为准。
-   <b>不写复习计划与“几轮复习”的时间表</b>。备考节奏因人而异，本文只讲结构。
-   <b>不写任何辅导机构、网课或资料商家</b>，也不评价任何考研老师。
-   <b>不写政策条款编号、办事窗口与联系方式</b>。需要链接处一律写「（链接待补）」。
-   <b>不比较“哪个学校/专业好考”</b>，也不写他人成绩与录取结果。

> 本文提到“国家线”“招生目录”这类词时
>
> 它们只是<b>你需要在官方文件里找到的位置</b>，不是本文的主张。具体数值与适用范围一律以当年官方发布为准。

## 流程概览：只写“有哪些环节”

考研可以拆成<b>四段</b>。前三段属于行政流程，第四段属于考查流程，<b>规则分别由不同主体发布</b>：

| 阶段 | 这一步在做什么 | 你要在这里确认的事 |
| --- | --- | --- |
| <b>① 决定方向</b> | 确定报考单位、专业方向与学位类型 | 招生目录里的科目与要求、是否需要额外材料 |
| <b>② 报名与确认</b> | 在官方渠道完成报名、信息确认与缴费 | 报考点选择规则、需要哪些证件、能否修改信息 |
| <b>③ 初试准备与参加</b> | 按科目结构复习，按官方安排参加初试 | 科目与大纲的官方版本、考场与证件要求 |
| <b>④ 成绩、复试与录取</b> | 成绩公布、复试线、复试考查、拟录取与后续手续 | 复试形式、材料要求、结果的正式形式 |

<b>这不是一张时间表</b>：各段的实际先后与重叠情况必须核实，本文不写时间。

### 科目结构：只有类别，没有科目名

初试的科目通常按<b>类别</b>组织。<b>具体科目名、分值、是否可选、有没有加试，全部待核实</b>：

-   <b>公共课类</b>：所有考生都要考的部分（通常含外语与思想政治理论类的科目；<b>具体名称与要求以当年官方大纲为准</b>）。
-   <b>基础/数学类</b>：部分专业要求，分为不同难度层次，<b>报哪个层次取决于报考专业的要求</b>。
-   <b>专业基础类 / 专业课类</b>：与报考方向直接相关的业务课，<b>差异最大</b>。
-   <b>复试环节</b>：初试之后的考查，通常含笔试、面试、外语能力考查等形式，<b>还可能有额外的附加材料要求</b>。

> “公共课”不等于“全校统一”
>
> 考试大纲与考察范围以官方发布的当年版本为准；部分专业还可能有加试或替代要求。<b>不要用往年的大纲当今年的大纲。</b>

### 材料与信息清单（只有类别）

身份与学历材料、报考信息（单位/专业/报考点/科目）、在校生与往届生各自需要的学籍或学历证明、复试材料（成绩单、陈述、成果材料等，<b>各单位要求差异大</b>），以及<b>官方文件本身</b>：招生简章、招生目录、考试大纲、参考书目。

> 把“官方文件”和“二手经验”分开放
>
> 建两个文件夹：一个只放<b>官方发布的招生简章、目录、大纲</b>，一个放经验帖。到关键判断时只看第一个，第二个只用来解释第一个里看不懂的部分。

## 需要核实的事实清单

每一条请写明<b>适用年份 + 报考单位/专业</b>。查不到就保持 `- [ ]`，不要猜。

- [ ] <b>要填什么</b>：报考该单位该专业需要满足的基本条件（学历、专业背景等方面的限制）。<b>去哪查</b>：当年招生简章与招生目录（链接待补）。

- [ ] <b>要填什么</b>：招生目录里列出的初试科目、各科目对应的官方大纲或参考书目。<b>去哪查</b>：招生单位的官方招生信息页（链接待补）。

- [ ] <b>要填什么</b>：是否区分学位类型（学术型/专业型）以及两者在科目与培养上的差别。<b>去哪查</b>：当年招生简章与目录（链接待补）。

- [ ] <b>要填什么</b>：报名渠道、报名信息的填写要点、哪些信息填错后无法自行修改。<b>去哪查</b>：官方报名系统内的说明与当年公告（链接待补）。

- [ ] <b>要填什么</b>：报考点的选择规则（应届生、往届生、异地报考分别怎么选）。<b>去哪查</b>：当年报考公告与报考点说明（链接待补）。

- [ ] <b>要填什么</b>：报名确认的流程与所需证件（线上还是线下、需要哪些原件）。<b>去哪查</b>：当年报考公告（链接待补）。

- [ ] <b>要填什么</b>：准考证的获取方式与考场相关要求。<b>去哪查</b>：官方报名系统说明（链接待补）。

- [ ] <b>要填什么</b>：学历学籍的在线验证或认证渠道怎么用。<b>去哪查</b>：<a href="https://www.chsi.com.cn/">中国高等教育学生信息网</a> 的官方说明。

- [ ] <b>要填什么</b>：初试成绩的公布渠道与复核（查分/复核）流程。<b>去哪查</b>：招生单位与省级招生考试机构的当年公告（链接待补）。

- [ ] <b>要填什么</b>：复试的基本形式与考查内容（几轮、笔试还是面试、是否含外语环节）。<b>去哪查</b>：招生单位当年的复试办法（链接待补）。

- [ ] <b>要填什么</b>：复试所需材料的清单与格式要求（成绩单、陈述、成果材料等）。<b>去哪查</b>：招生单位当年的复试通知（链接待补）。

- [ ] <b>要填什么</b>：复试比重的计算口径（初试与复试各自如何计入总成绩）。<b>去哪查</b>：招生单位当年复试办法（链接待补）。<b>注意</b>：填的是“口径怎么定”，不是推广某个公式。

- [ ] <b>要填什么</b>：调剂的规则与操作渠道（什么情况下可以调剂、通过什么系统）。<b>去哪查</b>：当年官方调剂系统的说明（链接待补）。

- [ ] <b>要填什么</b>：拟录取之后的后续手续（政审、档案、体检等）由谁通知、什么时候办。<b>去哪查</b>：招生单位当年通知（链接待补）。

- [ ] <b>要填什么</b>：特殊类型考生（如加分、专项计划、同等学力）的额外要求与材料。<b>去哪查</b>：当年招生简章与专项计划公告（链接待补）。

- [ ] <b>要填什么</b>：在校生备考期间与本校学籍相关的注意事项（实习、毕业设计、课程安排之间的冲突如何沟通）。<b>去哪查</b>：院系教务与辅导员（链接待补）。

- [ ] <b>要填什么</b>：对流程中的结果有异议时的正式申诉渠道与时限。<b>去哪查</b>：招生单位与相关部门正式发布的申诉流程（链接待补）。

- [ ] <b>要填什么</b>：没被录取时通常有哪些后续选择（再考、就业、其他升学途径）。<b>去哪查</b>：辅导员、院系教务与亲历者（链接待补）。

> 填写时的三条纪律
>
> 1.  <b>注明适用年份与报考单位</b>；不同单位的规则差异大，不注明等于无效信息。
> 2.  <b>区分“文件写的”和“我经历的”</b>：前者写文件出处与年份，后者写“某年某专业个人经历”。
> 3.  <b>不确定就留空</b>。尤其是分数线、时间点、科目这类信息——<b>留空比写错安全得多</b>。

## 怎么自己找信息

| 渠道 | 能得到什么 | 注意事项 |
| --- | --- | --- |
| <b>招生单位的官方文件</b> | 科目、大纲、复试办法、录取流程的权威口径 | 以当年发布为准；<b>不要拿往年的当今年用</b> |
| <b>官方报名与学籍平台</b> | 报名、准考证、调剂、学历验证等系统说明 | 只以平台内的官方说明为准，不靠转述 |
| <b>人</b>（学长学姐、院系教务、辅导员） | 备考节奏、复试氛围、本校考生的流程细节 | 他人经验只对那一年那个单位成立；多问几个人 |
| <b>公开资料</b> | 了解“有哪些科目类别”、通用技能与工具 | 只当参考；<b>以官方大纲和参考书目为准</b> |

<b>可用的公开入口</b>：学历学籍相关的官方说明见[中国高等教育学生信息网](https://www.chsi.com.cn/)；校内通知与办事流程从[信息门户](https://info.tsinghua.edu.cn/)入手；课程与教学材料在[网络学堂](https://learn.tsinghua.edu.cn/)；文献与数据库见[图书馆](https://lib.tsinghua.edu.cn/)；升学与就业相关信息见[学校就业信息网](https://career.tsinghua.edu.cn/)；校外访问校内资源见 [WebVPN](https://webvpn.tsinghua.edu.cn/)。<b>报考单位招生信息页的具体网址（链接待补）</b>——请从学校正式入口进入，不要依赖转发的截图或二维码。

<b>学生自发维护的资料库</b>（与学校官方无关，可能过期，且不一定覆盖考研）：

## 常见误解

以下几条<b>不依赖任何当年的具体政策</b>：

1.  <b>以为考试大纲和参考书目常年不变。</b> 自命题科目的范围与书目由招生单位发布，<b>可能调整</b>。用旧版大纲复习，风险不在效率，而在方向。
2.  <b>以为报名信息写错可以随时改。</b> 报名与确认环节有硬性要求，部分字段一旦确认就无法自行修改。<b>信息核对本身就是备考的一部分。</b>
3.  <b>以为过线就等于录取。</b> 初试只是第一道门槛，复试是独立的考查环节，且有自己的一套规则。<b>把全部准备压在初试上，是常见的结构性风险。</b>
4.  <b>以为别人的复习时间表可以直接照搬。</b> 他人的计划建立在他自己的基础、目标单位和专业难度上。<b>该照搬的是结构和核查习惯，不是钟点。</b>
5.  <b>以为可以只靠二手经验做判断。</b> 经验帖能告诉你“有哪些坑”，但<b>规则只写在官方文件里</b>；把经验帖当规则用，是考研里代价最大的一类误解。
