课程资料从来不止一个来源。有人整理往年题，有人写复习提纲，有人把课件和作业答案放上云盘， 还有人专门做「上这门课需要会什么工具」的引导文档。<b>它们的强项、更新节奏和版权状态都不一样</b>， 所以这一页不做简单罗列，而是把每个库的分工和边界写清楚。

## 能按课程查的四个资料库

这四个库的目录已经被扫成了[课程资料索引](/courses/)，可以按课程名、 资料类型直接筛。下面写的是各自的来头与边界。

### 计算机系课程攻略

89 门课

计算机系同学自发维护

按学期组织的课程目录，每门课下面放往年题、作业、笔记、速查表。同类项目里材料最全的一个。

<b>强项：</b>往年题与考试资料最全，覆盖从大一到大四加研究生

<b>注意：</b>库里「数据结构」那门课的 README 原话是「不要再 Naive 地背这个 Repo 里的东西了……每年 Cheatsheet 都会回收」——题目每年会变。资料用来复习和对照思路，不是用来押题或交作业。

许可：贡献者编写部分采用 CC BY-SA 4.0；课程材料版权归各自作者

-   [校内 GitLab 镜像](https://git.tsinghua.edu.cn/pkuanonym/REKCARC-TSC-UHT)校园网校内浏览与克隆都快得多，也不消耗国际流量
-   [GitHub 仓库](https://github.com/PKUanonym/REKCARC-TSC-UHT)需代理国内访问时通时不通，打不开就挂代理

## 用这些资料时，不能越过的那几条线

1.  <b>往年题用来看「考什么」，不用来背答案</b>课程攻略库自己写得很清楚：题目每年会变，助教也知道这些库存在。把往年题当复习提纲和难度参考，而不是押题册；直接把答案抄进作业或实验报告，属于抄袭。
2.  <b>作业答案只用来对照思路</b>看完答案自己重写一遍，和复制粘贴是两件事。多数课程对「雷同作业」的判定并不需要一模一样 —— 思路、变量名、错误都相同就足够说明问题。
3.  <b>不把课程内部材料往公开库上传</b>老师发的课件、内部讲义、考试原卷、含他人信息的名单与成绩，都不应该出现在公开仓库或网盘里。这一类东西一旦外传，责任在传的人身上。
4.  <b>尊重原库的许可与署名</b>这些库多为 CC BY-SA 或 CC BY-NC-SA 许可：可以转载和改写，但要署名、非商业使用、并以相同方式共享。直接搬运时请把原库和作者一起带上。
5.  <b>发现侵权内容，走原库的 Issue 渠道</b>如果你是被收录材料的作者且不希望公开，去对应仓库提 Issue 要求下架，比在群里抱怨有效得多。本站只做索引，不代为删除任何第三方内容。

## 怎么把资料库拿到本地

在线翻页适合找单个文件；想批量用（比如 grep 自己的笔记），克隆到本地更快。几条实测经验：

终端窗口

```
# 校内 GitLab 镜像：校园网内最快，也不消耗国际流量git clone https://git.tsinghua.edu.cn/pkuanonym/REKCARC-TSC-UHT.git# 只看课程目录结构、不要历史（仓库里有大量 PDF，完整克隆很大）git clone --depth 1 <镜像地址>
```

> 仓库体积比想象中大
>
> 课程资料库里 PDF、PPT 很多。实测<b>完整克隆计算机系课程攻略会占用约 10 GB 磁盘</b>。 如果只是想要某一两门课，优先用网页端进目录逐个下载，或者用 Git 的稀疏检出 （`git sparse-checkout`）只拉需要的目录 —— 先在校园网里试 `--depth 1`，别一上来就全量克隆。

> 校园网里的现实
>
> GitHub 在国内<b>时通时不通</b>（网页端延迟高、有时超时；`git clone` 走 SSH 一般没问题）。 所以上面这些仓库优先找校内 GitLab 镜像；没有镜像的，打不开时挂代理再拉。 判断方法与实测见[校内常用链接](/guides/links/#%E6%A0%A1%E5%9B%AD%E7%BD%91%E9%87%8C%E6%89%93%E4%B8%8D%E5%BC%80%E7%9A%84%E4%B8%9C%E8%A5%BF)。

## 找到资料之后

资料本身不会告诉你「怎么用才不算越界」。三条最短的规则：

1.  <b>往年题看题型和难度，不背答案</b>：题目每年会变，押题通常会失望。
2.  <b>作业答案对照思路，不复制</b>：看完自己重写，和粘贴是两件事。
3.  <b>发现侵权内容走原库 Issue</b>：本站只做索引，不代为删除第三方内容。

完整版写在[作业、引用与 AI：学术规范的边界](/academics/academic-integrity/)， 以及上面那份「不能越过的那几条线」。

## 和经验型、官方型资源的区别

上面这些是<b>课程级资料库</b>（往年题、笔记、课件）。另外还有两类资源，用途完全不同，别混着用：

| 想解决什么 | 去哪 | 注意 |
| --- | --- | --- |
| 「我该看哪一本」学习方法手册 | [官方学习手册与学习咨询](/guides/study-skill-handbooks/) | 学校官方机构发布，<b>只链接不镜像</b> |
| 「这条路真实长什么样」经验帖 | [校外经验站怎么用](/guides/external-guides/) | 许可差别很大，有的只能纯外链 |
| 「我这门课的资料在哪」 | 本页 + [课程资料索引](/courses/) | 你正在看的这一页 |

## 想补充一个新资料库

如果某个库确实值得推荐（公开、可访问、有持续维护），可以在 [怎么贡献一篇经验帖](/contribute/) 里提 Issue 或 PR。我们收录的标准是：

-   <b>公开可访问</b>：不需要付费、不需要把账号借给别人；
-   <b>说清来源</b>：谁维护的、内容许可是什么；
-   <b>不违反红线</b>：不收录含内部材料、他人隐私、付费导流的资源。

数据都在 `src/data/archives.ts` 里，加一条记录就行。
