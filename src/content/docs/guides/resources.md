这一页分两类：

-   <b>站内工具</b>（标着「站内」）——点开就能用：清单可以勾选、表格会自动算，数据存在你自己的浏览器里，不用下载任何文件；
-   <b>网盘资料</b>——文件本体<b>不存放在本站</b>，只给第三方网盘的外链。链接失效是常态。

## 新生入学

-   [新生报到清单（可在线勾选）](/freshman/arrival-checklist/)站内出发前的证件、到校当天、第一周的账号与基础设施——三条清单，勾选状态存在你自己的浏览器里。站内工具

## 学业与选课

-   [学分缺口拆解表（在线填 + 导出 JSON）](/academics/credit-planner/)站内把培养方案拆成「类别 → 学分下限 → 已修 → 缺口」，自动算每类还差多少学分。站内工具
-   [选课决策工作台（在线填 + 导出 JSON）](/academics/course-decision/)站内把候选课填成一张表，自动算出先修缺口、期末撞车、开学撞车与每周投入是否超载。不预置课程数据，规则公开可核对。站内工具
-   [《大学如何学》课程资料（学业方法模板）](https://cloud.tsinghua.edu.cn/d/b41948f21a62412087aa/)一门学业指导课的课件与模板：SQ3R 阅读法、备考计划表、甘特图与晨间日记模板、与导师沟通自评表、生涯决策平衡单、简历范例等。<b>适合「知道该努力但不知道从哪下手」的时候翻。</b>校内云盘链接核对于 2026-09-30

## 科研与深造

-   [联系导师 / 问老师事情的邮件怎么写](/mindset/talking-to-advisors/)站内邮件只要四件事：你是谁、你要什么、为什么找他、怎么继续。附写法与追问节奏。站内页面

## 为什么有的东西做成了站内页面，而不是发个模板文件

因为发过，然后发现没人用：

| 做成站内页面 | 做成模板文件 |
| --- | --- |
| 清单能直接勾，下次打开还记得勾到哪 | 下载一个 PDF，打印出来，勾完不知道丢哪了 |
| 表格改了数字立刻看到结果 | 下载一个 xlsx，公式被人改坏也没人知道 |
| 永远不会「链接失效」 | 网盘清一次，链接就死了 |
| 手机能直接用 | 手机上打开 xlsx 是一团糟 |

所以<b>能站内做的就不发文件</b>。真需要文件（要打印、要交给老师）的时候再说。

## 使用约定

> 下载网盘资料前请知悉
>
> 1.  <b>我们不对文件内容做担保</b>。下载后请自行判断是否适用于你的院系和年份。
> 2.  <b>链接可能失效</b>。网盘会清理、会限速，这是常态。
> 3.  <b>上传前请自查隐私</b>。任何包含姓名、学号、成绩、联系方式的文件，请先删掉这些信息再上传。
> 4.  <b>涉及官方表格的，请以学校发布的原始版本为准</b>。我们提供的只是「帮你少走弯路」的整理版。

## 暂时没有的几样东西，以及为什么

| 曾经打算做的 | 现在的结论 |
| --- | --- |
| 「选课时间线与决策表」 | <b>拆成两半处理</b>。「时间线」<b>不做</b>：时间节点每年变，站内放一份没人维护的表只会误导人，以教务通知为准。「决策」做成了[选课决策工作台](/academics/course-decision/)——它只整理你自己填的判断，不含任何日期或制度数字；决策顺序写在[各类课程怎么选](/academics/course-types/) |
| 「简历模板（docx）」 | <b>不做</b>。简历模板版本极多，求职季学校和院系通常会发官方版本；用来源不明的模板反而容易踩格式坑 |
| 「培养方案阅读笔记模板」 | <b>改做在线表格</b>：[学分缺口拆解表](/academics/credit-planner/) |
| 「新生报到物品清单（PDF）」 | <b>改做在线清单</b>：[报到第一周清单](/freshman/arrival-checklist/) |
| 「套磁信模板」 | <b>改成站内说明</b>：[怎么和老师、导师、辅导员沟通](/mindset/talking-to-advisors/)（结构比模板重要） |

## 手上有现成的资料？

非常欢迎。两种方式：

-   把文件传到你的网盘，然后把<b>链接和提取码</b>发到 [GitHub Issues](https://github.com/pan-nie/TsinghuaSurvive/issues/new)；
-   或者直接改 `src/data/resources.ts`，加一条记录后提 PR。 站内条目写 `internal: true` + 站内路径（`/xxx/`）；网盘文件写完整链接 + `code`。

> 收录标准
>
> -   <b>校内可访问、不强制登录、不反复跳转</b>的网盘体验最好；要填一堆信息才能拿到的，宁可不放。
> -   <b>不收录</b>：含个人信息或内部系统的文件、需要绕开权限才能拿到的材料、付费内容。
> -   体积大的（比如几十 MB 的课件包），建议放网盘而不是站内 —— 本站跑在 Cloudflare 上，流量和体积都有成本。
