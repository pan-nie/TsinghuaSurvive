关于奖学金，最该先知道的一件事是：<b>它不从大一开始评</b>。多数院系的评定对象是<b>大二及以上</b>年级本科生，时间点一般在<b>秋季学期开学后（9 月）</b>，评的是<b>上一学年</b>的表现。

所以大一的你和奖学金的关系不是“等评选”，而是：<b>这一年你做什么，直接决定明年 9 月你有没有东西可讲。</b>

本文讲三件事：评的是什么、怎么走流程、这一年该攒什么。制度性内容用两个院系的真实细则做实例，<b>任何数字都请回到你院系当年的细则去核对</b>。

> 本文的定位
>
> 本站不是官方渠道。下面出现的比例、金额、时间、可兼得关系都来自<b>已公示的院系细则原文</b>，用来让你理解“这类规则长什么样”。 它们<b>每年变、每院系不同</b>，请以你所在院系当学年发布的细则为准。

## 先看懂这套评定的三个设计

理解了这三条，后面的细节就都能推出来：

1.  <b>先评荣誉，再配奖金。</b> 荣誉和奖金是分开的两件事：先按类别评出“荣誉”，再根据荣誉去匹配相应的奖学金。所以规则里会写“所匹配奖学金不低于某个数”，而不是“这个奖发多少钱”。工物系的细则把这条写成原则：<b>荣誉与奖金相分离</b>。
2.  <b>分两大类：综合优秀奖，和一堆单项优秀奖。</b> 综合类看的是“全面发展”，单项类看的是“某一方面确实有东西”。两类之间通常<b>互斥</b>——拿到综合类原则上就不能再拿单项类（未央、工物两个院系的细则都这么写），所以申报时要选路线。
3.  <b>学业是入场券，不是加分项。</b> 入围通常先看学业成绩（绩点排名），而且很多院系明确写着：<b>上一学年有课程（含实践环节）不通过，不得申请综合优秀奖和学业类荣誉</b>。也就是说，学业掉下去不是“少一块分”，而是<b>直接失去资格</b>。

## 荣誉地图

把两个院系的细则放在一起看，荣誉清单基本是同一套：

| 层级 | 荣誉 | 看什么 |
| --- | --- | --- |
| <b>综合类</b> | 综合优秀奖 | 学业成绩 + 多方面表现加权排名；通常要<b>答辩</b> |
| <b>单项类</b> | 学业优秀奖 | 成绩优秀，或（高年级）成绩进步明显 |
|  | 科技创新优秀奖 | 竞赛、SRT、科研项目、论文、专利 |
|  | 社会工作优秀奖 | 校/院系学生组织或班团骨干岗位上的实际成效 |
|  | 社会实践优秀奖 | 实践支队、实践成果与社会影响 |
|  | 志愿公益优秀奖 | 志愿服务与公益事业的实际贡献 |
|  | 体育优秀奖 | 竞技成绩，或推动群体体育氛围 |
|  | 文艺优秀奖 | 文艺比赛、作品产出，或文艺氛围建设 |
|  | 全球胜任力优秀奖 | 海外学习实践、跨文化交流、国际组织实习等（部分院系<b>可空缺</b>） |
|  | 好读书奖 | 阅读积累、书评/作品产出、带动他人读书（部分院系<b>可空缺</b>） |
| <b>校级之上</b> | 国家奖学金、国家励志奖学金，以及若干校级冠名奖学金 | 一般从综合优秀奖的获得者里进一步评定 |

> 两个值得注意的细节
>
> -   <b>单项奖不只奖励“赢的人”</b>。科技创新、社会工作、实践、志愿这几类的评选条件里，都明确包含”<b>组织工作</b>“和”<b>带动氛围</b>“——办过活动、组织过支队、把一件事从零推起来，和拿奖牌一样算数。
> -   <b>每类单项奖的具体条件，细则里写得很细。</b> 想知道自己这一年做的事算不算，最靠谱的办法是<b>把当年细则里那一类逐条对着自己的经历看</b>，而不是问别人“我这个能不能评上”。

## 学校层面的几项大奖（2026 年口径）

院系细则决定你能不能入围，但<b>奖项本身是学校层面设的</b>。先认识这几个名字，它们在答辩现场、申请材料和往届经验里反复出现：

| 奖学金 | 设立年份 | 2026 年的额度与范围 |
| --- | --- | --- |
| <b>特等奖学金</b> | 1989 | 每人 <b>3 万元</b>；每年评选<b>不超过 10 名本科生</b>，表彰全面发展、综合素质优秀，或某一方面有突出表现并起引领示范作用的学生 |
| <b>国家奖学金</b> | 2002 | 每人 <b>1 万元</b>；国家在高校本专科阶段设立的最高荣誉 |
| <b>蒋南翔奖学金</b> | 1989 | 每人 <b>2 万元</b>；纪念蒋南翔校长，激励德智体美劳全面发展 |
| <b>一二·九奖学金</b> | 1987 | 每人 <b>2 万元</b>；由三十年代校友、日籍华裔企业家张宗植学长捐资设立 |
| <b>王大中奖学金</b> | — | 每人 <b>2 万元</b>；由王大中院士、高祖瑛教授伉俪捐赠设立，奖励刻苦读书、勇攀科技高峰的同学 |
| <b>邓稼先奖学金</b> | 2024 | 每人 <b>2 万元</b>；为纪念「两弹一星功勋奖章」获得者、校友邓稼先诞辰 100 周年而设 |

学校目前共有<b>各类奖学金项目 200 余项</b>，<b>超过 40% 的本科生</b>可以获得，奖励金额从 <b>2000 元到 30000 元</b>不等。

> 金额不是重点，资格才是
>
> 上面这些数字每年可能调整，<b>真正决定结果的是院系细则里的资格与名额</b>（见下节）。把它当成「知道有这些名字」，不要当成「我该奔着哪个数去」。

## 名额：不是“够格就有”

荣誉有名额上限，这是很多人第一次听到会意外的地方。以未央书院 2025-2026 学年度的细则为例（<b>仅作示例，务必看你自己的院系</b>）：

-   校级荣誉获得人数<b>不超过各年级参评人数的 50%</b>；
-   其中”<b>综合优秀奖</b>“不超过<b>各年级参评人数的 20%</b>。

这意味着两件事：<b>一是“达到条件”和“评上”之间还有一道排序</b>；二是<b>综合优秀奖的竞争强度明显高于单项奖</b>。选路线的时候，“我更适合冲综合，还是稳一个单项”，是个真问题。

## 流程：从申请到公示

两个院系的流程结构几乎一致，顺序如下：

1.  <b>本人自愿申请</b>（在规定窗口内，一般通过问卷或系统提交材料）。未央书院 2025-2026 学年度给的申请窗口是<b>9 月 17 日至 24 日</b>——注意这类窗口通常只有<b>一周左右</b>，错过就是等一年。
2.  <b>资格审查 + 公示</b>：工作组对满足基本参评条件的名单和申请材料进行<b>为期 3 个工作日的公示</b>（未央细则原文）。工物系的细则也要求申报材料真实有效、并愿接受公示。
3.  <b>综合类走函评 + 答辩</b>：先对材料做函评，据此确定<b>入围答辩的名单</b>，再组织答辩。单项奖里科创、社工、文体、志愿、实践这几类一般也要答辩；读书类通常只函评。
4.  <b>评审委员会审核 → 全系/全院公示 → 报学校复核</b>。
5.  <b>匹配奖金</b>（荣誉先定，奖金后配）。

> 别把公示当形式
>
> 公示期是<b>别人能对你的材料提出异议</b>的窗口。材料写不实、业绩没有证明，风险都在这一步暴露。细则里通常明确要求申报人保证材料真实，并接受公示。

## 材料：这一节最值得认真看

因为“你这一年做了什么”最终要变成<b>能被验证的材料</b>。工物系细则把证明方式写得很清楚，可以当通用参考：

| 证明方式 | 具体是什么 |
| --- | --- |
| <b>物证</b> | 比赛/奖励证书复印件、论文首页打印件或收录函、专利授权证明、学术专著封面及作者页等 |
| <b>书证</b> | 由分管这项工作的<b>证明人</b>签署情况属实。例如实验室科研活动的证明人是指导教师，团委任职经历由团委相关负责人证明，社团任职由社团部相关人员证明 |
| <b>成绩类</b> | 第二成绩单 + 上一学年已完工业绩的证明材料（申请单项荣誉通常必须提交） |

两个实操结论：

-   <b>从大一开始就把“证明”留好。</b> 证书、论文首页、活动推送链接、盖章证明，随手存一个文件夹。到了 9 月再回头找一年前的东西，是非常常见的翻车方式。
-   <b>岗位上做的事要说得出细节。</b> 个人自述里写“担任某职务”没有用，写“负责了什么、产出了什么、结果如何”才有用。这一条和[社工体系](/campus/student-organizations/)那一整页讲的是同一件事。

## 兼得规则：一年最多拿几项

这类规则最容易踩坑，因为它决定了你申请时该怎么排序：

-   <b>申请时可以同时报多项</b>（未央细则：可同时申请至多<b>三项</b>荣誉，并需给出<b>志愿排序</b>）；
-   <b>但最终拿到手的通常有上限</b>：未央是“最多 1 项综合优秀奖 + 1 项单项优秀奖，或最多 2 项不同类型的单项优秀奖”；工物系是“每名学生每年最多可获得<b>两项</b>不同的奖学金荣誉”；
-   <b>同类通常不可兼得</b>：在两个体系里获评的同类单项奖不可兼得；在院系外获评的校级奖学金，一般视为占用一项单项名额；
-   <b>有若干“不可兼得”的成组关系</b>（未央细则点名的：特等奖学金、一二·九奖学金、蒋南翔奖学金、王大中奖学金、邓稼先奖学金之间；国家奖学金与国家励志奖学金之间；全球胜任力优秀奖与社会实践/志愿公益优秀奖之间）；
-   <b>金额也有上限</b>：工物系细则是“每学年获得奖学金总额原则上不超过特等奖学金奖励金额”。

> 所以申请策略是什么
>
> <b>先想清楚你要哪一项</b>，再把志愿排序排好。常见的失误是“三项都报、排序乱填”，最后被分到一个自己并不匹配的类别，还占掉了名额。

## 两个院系的实例对照

把两个已公示的细则并排放，差异一眼能看出来——<b>这也是为什么本文坚持用“实例”而不是给一套通用数字</b>：

|  | 未央书院（2025-2026 学年度） | 工程物理系（2026 年） |
| --- | --- | --- |
| 评定对象 | 书院<b>大二及以上</b>本科生 | 全校<b>全日制本科生</b>，向所在院系申请 |
| 名单公示 | 资格名单与材料公示 <b>3 个工作日</b> | 初评人选上报→系内<b>公示</b>→校学生处复核 |
| 综合类 | 材料函评 → 入围名单 → <b>答辩</b> | 年级评审小组 → <b>答辩</b> → 评审委员会 |
| 单项类组织方式 | 按类别评审 | 读书类<b>函评</b>；科创/社工/文体/志愿/实践<b>答辩</b>，且不分年级 |
| 特色机制 | 校级荣誉 ≤ 参评人数 <b>50%</b>，综合优秀奖 ≤ <b>20%</b>；综合与单项原则上互斥 | 每类可推<b>首席获奖候选人</b>，全系评出少量首席获奖者，匹配<b>系设何东昌奖学金</b> |
| 成绩口径 | “上一学年”= 上一学年夏季 + 本学年秋季 + 本学年春季；<b>大二学生评奖不计入大一秋季成绩</b>（依书院决议） | 学业类参考<b>上一学年智育成绩</b>，并综合学习态度与进步幅度 |
| 兼得上限 | 最多 1 综合 + 1 单项，或 2 项不同类单项 | 最多 <b>2 项</b>不同荣誉 |

注意那两个“成绩口径”的差别：<b>同一个词“上一学年”，在两个院系指的学期范围不一样。</b> 这类细节只可能从细则原文里读到，问同学大概率得到的是“我那年好像是这样”。

## 反推：大一这一年该做什么

评选在大二，但材料在大一就攒下了。按重要性排：

1.  <b>先把学业守住。</b> 它是入围门槛，而且“有课程不通过”会直接砍掉综合优秀奖和学业类荣誉的资格。方法见[绩点到底是怎么算的](/academics/gpa/)和[考试、退课与重修](/academics/exams-and-retake/)。
2.  <b>选一条“有产出”的线深耕。</b> 科创（SRT、竞赛、论文）、社工（一个能干出结果的岗位）、实践（一次当支队长的经历）、志愿（累计服务时长）——<b>任一条做到有物证或书证，就有一个单项奖的着力点</b>。四条线都浅尝，往往一条都写不出材料。
3.  <b>留证据。</b> 上面「材料」那一节说的事，从第一学期就开始做。
4.  <b>别只盯着钱。</b> 奖学金在保研、申请、求职里是履历的一部分，而它的评定标准本身就是一份“大学里什么被看重”的清单。就算不为了评奖，照着它规划一年也不算亏。
