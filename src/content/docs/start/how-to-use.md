## 这里有什么、没有什么

本站只有四类内容，刻意保持简单：

| 类型 | 在哪 | 用途 |
| --- | --- | --- |
| <b>经验帖</b> | 「新生入学 / 学业 / 科研与深造 / 校园生活 / 心态与避坑」 | 具体问题怎么写、怎么选、怎么避坑 |
| <b>课程索引</b> | 「[课程与资料](/courses/)」 | 哪门课在哪个公开资料库里有材料，以及用这些资料的红线 |
| <b>工具与技能</b> | 「[技能入门](/skills/)」和「实用工具」下的[校内常用链接](/guides/links/)、[资料下载](/guides/resources/) | 上手要用的方法，和不用再翻聊天记录的直达入口 |
| <b>说明页</b> | 你现在看的这篇，以及[免责声明](/start/disclaimer/) | 约定边界，避免误用 |

<b>没有的东西</b>：没有评论区，没有账号系统，不收集你的任何信息。想反馈就通过页脚的 GitHub 入口，或者直接联系写这篇的人。

## 先按阶段或主题找，别从头读

不知道从哪看起的话，用这两个入口：

-   [<b>按阶段浏览</b>](/stages/)——你现在是新生、低年级还是临近毕业？每个阶段该关心什么不一样。
-   [<b>按标签浏览</b>](/tags/)——你已经知道自己要找什么（选课、绩点、保研、食堂……）。

这两个页面<b>不是手工维护的</b>，而是从每篇文章的 frontmatter 自动聚合的。所以文章一多，它们会自动变准。

## 页面上的几个标记

链接页上有四个角标，分别回答四个不同的问题，别把它们混成一个「可信 / 不可信」的判断：

-   <b>需校园网 / 公网可开 / 未实测</b>：这个入口要不要连校园网或学校 VPN 才能用。
-   <b>实测可访问</b>：脚本（`npm run check:links`）测过，域名活着、返回正常状态码。<b>它只证明网址存在，不证明入口还是干你要找的那件事。</b>
-   <b>实测打不开</b>：最近一次自动实测失败。可能真的挂了，也可能只是需要校园网。
-   <b>脚本核对 / 人工核对 / 核对：待补</b>：这个入口有没有被核对过，以及是<b>谁</b>核对的。 脚本核对＝程序抓页面比对标题关键词（能确认地址指向对的服务，看不到登录后的内容）； 人工核对＝有人点进去用过。<b>「核对：待补」的条目别直接转发。</b>

文章卡片上还有两个标记：

-   <b>待核对</b>：这篇里有些制度性细节还没逐条核实过。
-   <b>内容可能已过期</b>：页面顶部的横幅。可能是作者明确标记了过期，也可能是<b>超过 6 个月没人重新核对</b>，看门狗自动加上的。

资料页上还有一个：

-   <b>待补充</b>：我们知道需要这份资料，但还没整理好。

> 警告
>
> 只要页面上出现了上面任何一种标记，就说明这块内容还没到“可以闭眼相信”的程度。涉及报名、截止、考核的事情，<b>一律去官方系统再确认一遍</b>。

## 搜索

右上角的搜索框是全站可用的，支持中文。因为中文没有词形变化，搜索时建议用<b>两三个字的关键词</b>而不是整句话：

-   搜「绩点」「培养方案」「保研」「选课」比搜「我想知道绩点怎么算」命中率高得多。
-   也可以按住 Ctrl/⌘ + K 直接唤出。

## 内容的时效性

经验类内容的保质期比想象中短。我们的做法是：

1.  每篇都在页脚显示<b>最近更新时间</b>（取自 Git 提交记录）。
2.  每篇底部有「<b>最后核对</b>」日期——填了这个日期，表示有人逐条核实过文中事实。没填则显示「尚未标注」，你就知道这篇没经过人工核对。
3.  <b>超过 6 个月没重新核对的内容，页面顶部会自动出现橙色提醒。</b> 这是自动的，不依赖有人记得。
4.  作者明确知道过期的内容，会标成红色警告，而不是直接删掉——因为“这篇过期了”本身就是有用的信息。
5.  每篇正文里会写「<b>以官方为准</b>」的那类细节，请当它是提醒，不是客套话。

## 发现错误怎么办

非常欢迎。三种方式，从轻到重：

-   维护者在页面底部点“编辑此页”，进入对应飞书文档修改；保存后网站定时同步。
-   到 [GitHub Issues](https://github.com/pan-nie/TsinghuaSurvive/issues/new) 描述问题，我们来改。
-   认识作者的话，直接微信拍他一下。

具体流程见[怎么贡献一篇经验帖](/contribute/)。
