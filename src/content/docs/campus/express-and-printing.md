这三件事的共同点是：<b>频率不高，但每次都要现学一遍</b>。而且它们的信息保质期最短——代收点会换位置、打印店会换老板、价格会调。所以这篇刻意<b>不写任何具体店名、位置、价格和营业时间</b>，只写怎么找、怎么选、怎么不出错。

## 这篇文章不做什么

-   <b>不写具体点位</b>。哪家代收点、哪个打印店在哪儿，一律不写——写错了你会白跑一趟，而且它随时会变。
-   <b>不写价格</b>。黑白和彩色、单面和双面、普通纸和铜版纸的差价结构可以讲，但具体数字每年都在动。
-   <b>不写营业时间</b>。营业时间是最容易过期的信息，请直接看现场公示或官方渠道。
-   <b>不推荐任何商家的付费服务</b>。这篇不导流，也不接推广。

> 先分清「事实」和「经验」
>
> 文中的流程类描述是<b>通常情况</b>，不是承诺。真正的规则（能不能代收、几点前下单、什么物品不能寄）<b>以现场公示和快递公司官方说明为准</b>。

## 快递怎么收：先搞清它最后停在哪

快递到校之后，通常会落在下面几种地方之一。你要做的不是背清单，而是<b>知道自己这一单属于哪一种</b>：

| 它最后在哪 | 你通常需要什么 | 主要风险 |
| --- | --- | --- |
| <b>校内代收点 / 驿站</b> | 取件码或手机号，有时要看证件 | 有营业时间；大件可能要自己搬 |
| <b>智能快递柜</b> | 取件码或扫码 | 超时可能收费或被退回 |
| <b>送到楼下 / 门口</b> | 接电话，尽快下楼 | 丢失风险最高，贵重件别选 |
| <b>院里或楼里的统一代收</b> | 问清由谁管、放哪 | 各家规则不同，<b>别默认别人有</b> |

<b>三件最实用的事</b>：

1.  <b>下单前把收件地址写成“能稳定送达”的形态</b>。校内地址和宿舍楼的具体写法，问一下同楼的人最快；快递面单上的地址只要能让快递员找到你这一栋就行。
2.  <b>下单后主动看物流</b>，别等短信。到件提醒可能被拦截成垃圾短信，也可能只发在快递公司的 App 里。
3.  <b>大件、生鲜、贵重件提前一周安排</b>。它们往往不能进柜、不能长期存放，卡在期末或假期最容易出事。

> 取件高峰是可以避开的
>
> 取件高峰和下课时间基本重合（中午、傍晚）。<b>同样的代收点，错开 20 分钟基本不用排队</b>。这条和[吃饭、自习与出门](/campus/food-and-study/)里避开食堂峰值的逻辑是一样的。

<b>假期和搬家季</b>是最容易出问题的两个时间点：代收点可能缩短时间或暂停、行李和网购件会同时堆在一起。<b>离校前先把在途快递处理掉</b>，比回来再想办法便宜得多。

## 寄件：留下痕迹比省几块钱重要

寄件只需要记住三件事：

1.  <b>走官方渠道下单</b>（快递公司自己的 App、小程序或官方客服）。通过不明来源的“代寄”下单，出了问题你查不到单号。
2.  <b>单号一定自己存一份</b>。截图或抄下来，放进手机备忘录。<b>没有单号的寄件等于没有凭证。</b>
3.  <b>贵重物品主动保价、主动验视</b>。保价和验视都是官方提供的选项，具体规则以快递公司说明为准；不保价时赔付上限通常很低。

> 寄之前先确认“能不能寄”
>
> 电池、液体、喷雾、刀具、证件、证件复印件、以及任何说不清来源的东西，<b>都可能被拒收或被扣</b>。拿不准就当场问工作人员，别抱着“试试看”的心态塞进去。

<b>寄重要材料给老师或单位</b>，优先考虑可查询签收的方式，并且在寄出后<b>把单号和签收情况一并发给对方</b>。这一条在申请季能省掉大量来回确认。

## 打印：先分清“自助”和“店里”

| 你的需求 | 更合适的做法 | 原因 |
| --- | --- | --- |
| 几十页黑白讲义、习题 | 自助打印 | 便宜、快、随时能做 |
| 彩色、大幅面、特殊纸 | 打印店 | 自助机通常做不了 |
| 装订、覆膜、裁切 | 打印店 | 需要人和设备 |
| 期末临时赶印 | <b>提前一天</b>，别赌 | 越临近截止越排队 |

<b>文件准备的四条</b>，比找哪家店重要得多：

1.  <b>交 PDF，不要交 Word</b>。换了电脑、换了字体，排版就会跑。
2.  <b>导出时嵌入字体</b>。这一步不做，公式和生僻字很可能变成方框。
3.  <b>先看一遍“打印预览”的页数</b>，确认没有空白页、没有半页断行。
4.  <b>双面还是单面、要不要页码，先想清楚再点打印</b>。打完才发现要单面，成本要翻倍。

> 自助打印的一般流程
>
> 通常是“上传文件 → 选参数 → 扫码或刷校园卡付款 → 取件”。<b>每家机器的操作顺序不同，第一次用先站在旁边看别人怎么操作</b>，比乱按快。印完记得核对页数，并<b>清掉自己在机器上留下的账号信息</b>。

## 装订与扫描

<b>装订</b>：按用途选，不要按好看选。

-   <b>交作业、交报告</b>：订书钉或长尾夹足够，重点是<b>别散</b>。
-   <b>要存档、要交到教务或单位的正式材料</b>：问清对方要求的装订形式（胶装、骑马钉、活页夹都有人要求），<b>先问再印</b>，装订完再改就是重印。
-   <b>页数多的论文</b>：留出足够的装订边距，否则装完字会被夹进书脊里。

<b>扫描</b>：

-   手机拍照转 PDF 在应急时够用，但<b>注意光线和阴影</b>，歪斜、反光的扫描件可能被退回。
-   需要正式提交时，<b>用平板扫描或打印店扫描</b>，并在提交前自己打开看一眼方向对不对。
-   扫描件务必<b>检查隐私</b>：证件号、他人姓名、批注、修订痕迹、文档属性里的作者信息，都可能在扫描件或 PDF 里被带出去。

## 跑腿类服务：能用在哪，不能用在哪

跑腿的本质是<b>用钱换时间</b>，它在下面这些场景里是合理的：代取快递、代买日用品、代办跑腿类的普通事务（排队、送件）。

> 这些事不要用跑腿，也不要在本站找办法
>
> <b>代课、代签到、代答到、代考、代写作业或论文、代做实验、伪造或代开证明</b>——这些不是“省时间”，是违纪违规，后果由你自己承担。本站不写、也不提供任何绕过规则的做法。
>
> 另外：<b>不要把身份证、校园卡、账号密码、验证码交给跑腿人员</b>，也不要让人替你签收需要本人确认的材料。省下的那点时间，不值得赌一次信息泄露。

<b>用跑腿前问自己两个问题</b>：这件事<b>必须今天办</b>吗？如果自己办，<b>最坏会耽误什么</b>？如果答案分别是“不是”和“没什么”，那多半不用花这个钱。

## 马上能做的：开学前的批量打印清单

开学第一周打印店最挤，<b>能提前打的现在就打</b>：

- [ ] 培养方案、课表、选课相关材料的打印件（需要纸质版时才打）

- [ ] 课程要求的教材配套讲义、习题册（<b>先确认版本和年份</b>，别打错版）

- [ ] 常用的表格模板：请假单、各类申请表的空白版（<b>从官方渠道下载的版本</b>）

- [ ] 实验记录本 / 笔记本用纸，以及一个能装 A4 纸的文件夹

- [ ] 证件照的多尺寸备份（纸质 + 电子版各留一份）

## 马上能做的：大作业 / 论文提交前的检查清单

提交前照着过一遍，能挡掉绝大多数“被打回来重交”：

- [ ] <b>最终版是 PDF</b>，且在<b>另一台设备</b>上打开确认排版没变

- [ ] <b>页数、页码、封面、目录</b>符合要求（要求在哪写着，就按那份文件对）

- [ ] <b>命名规范</b>：文件名按提交要求写，别用「最终版最终版2」

- [ ] <b>引用与署名</b>：引用格式、合作者署名、AI 使用说明都按课程或期刊要求处理，规则见<a href="/academics/academic-integrity/">作业、引用与 AI：学术规范的边界</a>

- [ ] <b>打印一页试印</b>，确认没有方框字、没有超出边距

- [ ] <b>留一份自己存档</b>（云端 + 本地各一份），并记下提交时间与提交回执

## 哪些东西取决于你的院系、宿舍楼和年份

-   <b>收件地址怎么写、快递到哪取</b>：取决于你住在哪一栋、哪个院系有没有统一代收点。<b>同一所学校里差别可以很大。</b>
-   <b>打印资源</b>：取决于你所在院系有没有对内的打印点、以及是否对本科生开放。
-   <b>装订与提交格式要求</b>：取决于具体课程、具体单位，<b>同一年不同课也可能不同</b>。
-   <b>代收点与快递公司的合作</b>：每年都会变，<b>别用往年经验判断今年</b>。
